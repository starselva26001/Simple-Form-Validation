# Simple Form Validation using HTML, CSS & JavaScript

## 📌 Project Overview

This project is a simple form validation application built using **HTML**, **CSS**, and **Vanilla JavaScript**.

The form contains three input fields:

* Name
* Email
* Password

The **Submit** button remains disabled until all required fields are filled with valid input. JavaScript is used to monitor user input and dynamically enable or disable the button based on the validation status.

## 🚀 Features

* Real-time form validation
* Name field validation
* Email format validation
* Password field validation
* Disabled submit button until all fields are completed
* User-friendly validation messages
* Responsive and clean user interface
* Built without any external libraries or frameworks

## 🛠️ Technologies Used
